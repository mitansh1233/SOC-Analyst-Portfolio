Simulated a network-based brute-force authentication attack targeting a local SMB share. Utilized Windows Event Viewer to filter, isolate, and extract malicious logon failures to build a threat profile based on Event ID 4625.

## 3. Threat Hunting & SOC Context
- **Technique Mapped:** MITRE ATT&CK T1110 (Brute Force) & T1078 (Valid Accounts).
- **Detection Logic:** Attackers automate authentication attempts against exposed services (RDP/SMB). A SOC detects this by establishing a threshold (e.g., >5 Event ID 4625s from a single Source IP within 5 minutes). 
- **Logon Type Context:** Logon Type 3 (Network) indicates remote targeting, whereas Logon Type 10 (RemoteInteractive) specifically flags RDP brute-forcing.

## 4. Remediation & Best Practices
- Implement Account Lockout Policies (e.g., lock account for 30 minutes after 5 failed attempts).
- Enforce Multi-Factor Authentication (MFA) on all network-facing services.
- Route Event ID 4625 to the SIEM to automate brute-force threshold alerting.
